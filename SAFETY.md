# Trading Desk boundaries

- Tally MCP tools read and update your journal. They never execute brokerage orders,
  change protective stops or authorize an autonomous trading strategy.
- No broker connector is required by this template. Do not interpret this setup as
  approval to enable execution on an AI host. Client permissions still apply.
- Keep confirmations for journal writes. A schedule can stall when a tool needs
  approval; verify that a scheduled checkup ran instead of assuming it did.
- Use sourced observations. Missing or old evidence is not a current reading.
- Closing a thesis changes its journal record only. Manage an actual position separately.
- Records remain private unless the owner explicitly publishes a receipt.
- Existing optional Propr accounts retain their separate web authorization and controls.
  Disconnecting a key does not itself close positions. Inspect account state before removal.

This template supports accountability. It does not guarantee alerts, an edge or profits.
